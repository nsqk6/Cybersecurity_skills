# 决策规则速查 — 移动安全

| 能力 | 一句话规则 |
|---|---|
| 攻击面切分与测试面规划 | 先按信任边界分层列全、锁范围/变体/环境/敏感数据、再用可达性与五阶段收敛，跳段就出假阳性报告。 |
| 组件导出判定与利用 | 三条路径取并集判导出，再用最小权限载体与上下文等级双闸门定级，最后按 Activity/Service/Broadcast 选利用手法。 |
| Content Provider 数据抽取 | 先证原路径被拒再变形绕权限，projection 单引号起手经 sqlite_master 拖表，hosts 探针加 ../ 取文件，双 scanner 交叉确认才落笔。 |
| 沙盒数据获取 | 沿路径逐级看 x 位并在普通上下文实测，allowBackup 三步导出解包再写回验证，debuggable 用 run-as 以应用身份取数。 |
| WebView 与客户端注入链 | 先定加载源再查 WebSettings 默认值，Bridge 按 targetSdk 17 分界判 RCE，ZipSlip 以应用权限篡改自身沙盒且须有替换 zip 前提。 |
| 传输校验与 pinning 对抗 | 先不装 CA 抓一次定档，装 CA 再抓分中档，仍失败先排双向认证再判 pinning，最后按实现层选 patch 或 hook。 |
| 脱壳与动态 Hook | dex 与 Manifest 交叉识别加固，三处找源 APK，dvmDexFileOpenPartial 断点 dump 内存 dex，反调试改 TracerPid，够用即停。 |
| 静态逆向与重打包插桩 | dex 按执行时机定位校验点并重签插桩，iOS 非越狱需未加密二进制插 Gadget，otool 查三项免费防护，fuzz 按选目标→生成→投递→监控四环最弱项定产出。 |
| iOS 平台入口与本地认证测试 | scheme 按注册→handler→三项校验→fuzz 五步测，存储看属性匹配敏感度，生物识别须解锁密钥，越狱检测按执行时机选绕过并先排除崩溃。 |
| 认证量化与发现定级闸门 | 认证套四条量化线与口令分档，扫描告警先核攻击链可达性，保留项五轴打分取最弱轴写成利用前提，让读者能复算定级。 |
| 移动安全 · OCR 增补：方法论框架与判据 | 从 3 个扫描件 OCR 单元中按「方法论框架与判据」检索方法与判据。 |
| 移动安全 · OCR 增补：可执行配方与排障 | 从 23 个扫描件 OCR 单元中按「可执行配方与排障」检索方法与判据。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
