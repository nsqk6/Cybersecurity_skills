# 决策规则速查 — 硬件与物联网安全

| 能力 | 一句话规则 |
|---|---|
| 设备发现与暴露面评估 | 用二层标识找设备、用可关联性判暴露；扫不到不等于不存在。 |
| 远程隐身接入链路的搭建与保护范围判定 | VPN加密链路、代理改写目的地，叠加才互补；匿名只解决"谁访问"不解决"内容可读"。 |
| 远程节点寻址与现场部署 | 静态内址消除租约漂移，DDNS把动态公网IP绑到固定域名，先评估暴露代价再开端口。 |
| 默认凭据与最小服务加固 | 先枚举入口，再分别修默认凭据（认证）、加密明文通道（加密）、裁剪不必要服务（减入口）。 |
| 供电与硬件可靠性排查 | 先查电源轨再查配置；续航=容量÷平均电流，判据是换电源后现象消失。 |
| 板级总线与外设连接 | 先选连接方式再开总线、最后保电平；有5V引脚不等于IO能承受5V逻辑。 |
| 启动链与整卡镜像操作 | 物理接触即启动链控制；整卡按字节克隆，OTP 熔丝比日志更难伪造。 |
| 嵌入式任务持久化：MCU 固件与 cron | 单一闭环动作且无需OS就用MCU固件驻留，需要OS就用幂等脚本+cron调度。 |
