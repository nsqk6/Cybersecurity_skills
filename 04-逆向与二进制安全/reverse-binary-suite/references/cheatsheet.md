# 决策规则速查 — 逆向与二进制安全

| 能力 | 一句话规则 |
|---|---|
| 陌生二进制逆向流程 | 拿到陌生文件先分类→摘要→深度检测，再从失败提示用交叉引用反攻决策点，静态结论必须动态验证 |
| 恶意样本分阶段行为分析 | 静态初筛→排除反虚拟化→三面全量监控→只对可疑点开调试器→汇总结论与YARA，先全量后过滤 |
| 脱壳与反分析工具链 | 四信号判加壳，执行断点或PUSHAD-POPAD找OEP，按覆盖风险选断点，dump后重建IAT并修复去同步 |
| 威胁建模与审计规划 | 五阶段威胁建模产出组件风险排序，四阶段+plan/work/reflect日循环控节奏，DREAD与KLOC定优先级和工期 |
| 源码审计数据流与候选点回溯 | 正向追数据流+反向候选点回溯交叉验证，ACC/函数审计日志沉淀判断，黑盒补特殊状态可达性 |
| 内存破坏与整数漏洞定位 | 内存破坏用六问评级，整型分符号转换/符号扩展/截断三类验证，逆向侧看助记符与缓冲区长度比对 |
| 注入与过滤器绕过审计 | 危险集减过滤集判注入，允许集交危险集判过滤器强度，剥离顺序/编码顺序/原语替换三类结构化绕过 |
| 协议解析与竞态审计 | 单包按可信基准逐层扣减、TLV先校验剩余再减法、病态分片看两端解释差异；竞态看共享状态+可中断窗口+外部可触发三要素 |
| 特权边界与 Windows 对象审计 | 降权分永久/临时双路径逐项核，fd查CLOEXEC，Windows查搜索顺序与命名空间抢占，RPC用十条清单+三跳指针定位接口 |
| 从崩溃到可控利用的推进 | 崩溃点回溯三步法定位根因，二分+pattern定偏移，标记串校准落点，NOP+int3验证跳转链后放shellcode |
| 缓解绕过与 ROP 链编排 | SEH借分发器完成ret，GS靠异常抢先跳过cookie检查，DEP靠关NX或ROP改权限，ASLR靠栈上指针减固定偏移定位API |
| Shellcode 工程化 | GetPC解决位置无关、等价重构消除null坏字符、egg hunter在空间不足时藏代码再找回、Unicode场景做venetian对齐 |
| 模糊测试战役工程 | 选题取甜区、接口绕过文档查关联表、先跑最便宜fuzzer再逐级加智能、种子按功能覆盖、多fuzzer跨档位并联、用边际期望而非时长决定停机 |
| 崩溃分诊与 fuzz 基础设施 | 三级指纹去重且保留全部样本，最小化到必要充分集，补子进程/静默越界监控，结论分级，覆盖率做健康闸门与搜索方向 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
