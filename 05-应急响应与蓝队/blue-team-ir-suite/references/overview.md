# 应急响应与蓝队 — 域总览

## 这个域解决什么问题

这里处理的不是「装什么设备」，而是**已经出事之后怎么把顺序走对、怎么把证据留住、怎么从日志里把入侵链拼回来，以及平时怎么把检测规则做成可维护的东西**。本域 12 个能力按「响应 → 取证 → 溯源 → 检测 → 体系」组织，每张卡都指向一个值守或处置时会真实遇到的判断。

## 能力地图

| 二级分类 | 能力 | 一句话规则 |
|---|---|---|
| 取证与溯源 | `attacker-attribution` · 攻击者身份溯源 | 这个能力解决的问题是： 已有攻击者的某个锚点（一个 uid、一个域名、一封邮件、一次扫描连接），能不能收敛到"是谁" |
| 检测与响应 | `containment-decisions` · 抑制与隔离决策 | 这个能力解决的问题是： 事件正在发生，必须立刻决定"断什么、不断什么、先救什么" |
| 工程化 | `defense-readiness-baseline` · 蓝队基础能力建设与暴露面收敛 | 这个能力解决的问题是： 预算、人力、时间都有限，蓝队能力应该按什么顺序建，才不会建出一堆互不衔接的设备和规则 |
| 检测与响应 | `detection-rule-engineering` · 检测规则与日志管道工程 | 这个能力解决的问题是： 告警写了一堆，但要么不响，要么响得没人看 |
| 工程化 | `detection-validation-coverage` · 检测覆盖度与有效性验证 | 这个能力解决的问题是： "设备装了、规则写了、告警没响"，到底是没攻击，还是坏了 |
| 检测与响应 | `host-triage-parallel` · 主机现场多线并行排查 | 这个能力解决的问题是： 拿到一台（或一批）可疑主机，不知道从哪查起，也不知道查到什么程度算查完 |
| 检测与响应 | `incident-scoping` · 影响范围圈定与攻击链回溯 | 这个能力解决的问题是： 一台机器确认失陷后，"还有没有别的"和"从哪进来的"这两个问题都必须回答，否则清理等于没做 |
| 检测与响应 | `ir-evidence-order` · 应急响应取证与处置顺序 | 这个能力解决的问题是： 事件已确认，但现场只有一次，而接下来每一个动作都会销毁一部分证据 |
| 工具链 | `ir-toolchain` · 应急工具链与样本快检 | 这个能力解决的问题是： 方法知道了，但手上该拿什么工具、以什么顺序跑、哪些参数会让证据消失 |
| 取证与溯源 | `log-forensics-integrity` · 日志取证与完整性反推 | 这个能力解决的问题是： 攻击者会清日志，而"日志里没有可疑记录"到底是"没发生"还是"被删了"，必须能区分 |
| 取证与溯源 | `persistence-sweep-windows` · Windows 持久化点全量排查 | 这个能力解决的问题是： "重启之后木马又活了，但 Autoruns / 任务计划程序 / services.msc 里找不到 |
| 取证与溯源 | `traffic-hunt-c2` · 流量形状与隐蔽信道狩猎 | 这个能力解决的问题是： 流量全程加密、没有解密能力，甚至没有已知恶意 IOC，还能不能发现 C2 与外传 |

## 域的共性失败模式

（下列条目逐条摘自各能力卡 B 段，均为语料中作者明确写出的坑）

- **attacker-attribution**：**拿到代理 IP 就停止**：没看 `X-Forwarded-For`，也没考虑拿下代理服务器看连接。
- **containment-decisions**：**不隔离先分析**：边分析边扩散（勒索场景尤其致命）。
- **defense-readiness-baseline**：**从第 6 层开始买 SIEM/态势平台**：前五层空着，告警无法归属。
- **detection-rule-engineering**：**默认全开采集**：存储爆炸且无人分析（原书明确警告）。
- **detection-validation-coverage**：**用"插入一条告警记录"代替真实事件**：链路后段全没验证到。
- **host-triage-parallel**：**只做进程排查**：找不到无文件载荷、纯计划任务型驻留、WMI 订阅（《windows应急响应手册》多处强调）。
- **incident-scoping**：**只处理告警那台机器**：攻击者刻意多点、异构，清掉最显眼的据点，其余转静默（《蓝队视角下的防御体系突破》· 多点潜伏）。
- **ir-evidence-order**：**先杀毒再排查**：样本与内存态双失，无法定家族、无法定损、无法判断入口（《windows应急响应手册》全书的段落顺序即针对此）。
