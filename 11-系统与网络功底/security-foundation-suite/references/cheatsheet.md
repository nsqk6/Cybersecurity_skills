|---|---|
| 文本处理管道排查 | 面对行式文本按「选行→整形→聚合」三段拆开，逐段追加、每段可见，最后固化为可复跑的一行命令。 |
| 字段与正则正确性 | 结果可疑时按 shell 引号→sed 正则方言→不可见字符→字段匹配语义→NR/FNR 逐层排除静默失效。 |
| 批量文件操作与传递 | 先判下游是否需逐文件独立上下文，再选 \; / + / xargs，执行前把动作换成 ls -l 空跑并留副本。 |
