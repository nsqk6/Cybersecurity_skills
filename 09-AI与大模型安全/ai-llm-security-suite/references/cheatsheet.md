# 决策规则速查 — AI与大模型安全

| 能力 | 一句话规则 |
|---|---|
| Agent 三层护栏与独立审查架构 | 先定数据层最后一道门再回溯补执行层与上下文层，把所有自我判断迁出同一上下文，并用异构模型+换模态和双向样本评估护栏。 |
| 注入面清点与指令/数据分离 | 按工具清单清点注入入口与隐蔽载体，用来源标记+角色体系降格外部内容，并把封堵落到执行器鉴权、动作侧限制与逐行代码审查。 |
| 泄露面与攻击后果分类判据 | 按输入/输出/训练/API 四类盘点被动泄露，按后果是否落到真实系统区分注入与越狱，再路由到对应加固层。 |
| 第三方工具/MCP/Skill 准入审查 | 先算致命三要素四元组并削掉一条，再把 description 当不可信文本通读、Skill 当代码审，最后用 tool_filter 把能力面收窄到必需集合。 |
| 工具执行安全与服务端真值校验 | 调用前绑定会话身份，事实取服务端真值、expected_* 只做 checklist，调用前插 Sidecar 与命令语义解析，按可信度隔离并控出口，最后按幂等性定重试。 |
| RAG 权限过滤与投毒注入防御 | ACL 下推到检索召回阶段并按租户分区，检索结果加来源标记，且有副作用的动作不得仅凭检索内容触发。 |
| 记忆与自进化安全边界 | 状态栏由代码确定性维护，反思输入分可信/不可信，自改写产物进待验证区，证据与指令隔离且安全机制对 Agent 只读。 |
| 委托忠诚与多 Agent 信任边界 | 在 Harness 层写死忠诚对象与守则并实测两端，A2A 侧用 mTLS、全量审计、header 凭证与发现端点保护建立传输基线。 |
| 越狱提示词构造与失效判定 | 按七个失效层归类手法并提取成立前提，再用 Prompt×AI理解=输出质量 与安全水位两个判据判跨模型和时代有效性，最后给对称防守面。 |
| AI 辅助漏洞研究与 POC 迭代 | 用双阶段精神内核+能力矩阵+自我验证造助手，再走背景→利用研究→生成POC→反馈迭代四步直到触发。 |
| 对抗奖励操纵与博弈欺骗边界 | 确认奖励通道可影响后用随机化 Hedge/Exp3 替代贪心，按确定性玩家判脆弱性，并把一次性交互改造成可观测可报复的重复博弈。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
