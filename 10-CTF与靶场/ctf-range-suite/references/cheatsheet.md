# 决策规则速查 — CTF与靶场

| 能力 | 一句话规则 |
|---|---|
| AWD 攻防节奏与 flag 通道 | 这张卡处理与解题赛（Jeopardy）完全不同的竞赛形态：**AWD（Attack With Defense，攻防赛）** |
| 无附件盲打：从探针到 BROP | 这张卡处理 pwn 题里前提最苛刻的一类：**没有附件、也没有任何泄漏原语，只有一个会崩溃后重启的 ip:port** |
| 文件读与包含：从确认漏洞到 getshell | 这张卡把「任意文件读 / 文件包含」这一类漏洞从「确认存在」一路推进到「拿到 shell」 |
| 格式化字符串漏洞的四步利用 | 这张卡处理一类「把用户串当格式串用」的漏洞：`printf(user_input)`、`sprintf`、`fprintf` 等调用把攻击者控制的字符串直接当格式串解析 |
| Linux 靶场提权：路线排序与配置错误 | 这张卡处理「已经拿到一个低权限 shell，怎么升到 root」这段靶场常见困境 |
| 靶场推进：阶段交付物与止损判断 | 这张卡处理的是「面对一台未知靶机，怎么推进才不浪费时间」的元层能力 |
| Pwn 题型起手：可打面与保护组合判读 | 这张卡解决的是 pwn 题最早、也最容易浪费时间的那个决策：**在写第一行 payload 之前，这道题到底能怎么打、该往哪个方向打** |
| 命令执行外带与反弹 shell 落地 | 这张卡处理命令执行类漏洞在「命令已经能发出去，但拿不到可用结果」这一整段困境 |
| Web 起手：元信息收集与源码泄露推进 | 这张卡处理 Web 题最早的一段：**在找注入点之前，先把题目暴露的元信息收干净，并在拿到源码泄露后一路推进到 flag** |
| Web 漏洞判型与利用通道选择 | 这张卡处理 Web 题里「已经看到一个可疑输入点，但不知道它属于哪类漏洞、该走哪条利用通道」的阶段 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
